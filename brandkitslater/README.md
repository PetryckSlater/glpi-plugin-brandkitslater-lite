# BrandKitSlater Lite (Community Edition)

Plugin de customização visual avançada e Theming para GLPI 10 e GLPI 11.

- **Nome Técnico:** `brandkitslater`
- **Versão:** `1.0.0-lite`
- **Autor:** Petryck Slater
- **Licença:** GPL-2.0

Para documentação completa, instruções de instalação e suporte a presets visuais, consulte o `README.md` na raiz do repositório ou acerte a configuração em **Configurar > BrandKitSlater Studio** no seu painel GLPI.
